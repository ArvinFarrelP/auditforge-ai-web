# AuditForge AI — Landing Page

Official landing page for **AuditForge AI**, an AI-assisted Solidity smart contract pre-audit platform.

Built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
